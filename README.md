# 🚀 LeaveDesk - Online Leave Management System

LeaveDesk is a responsive web application designed to streamline and automate leave requests for students and employees. It replaces manual paperwork with a clean, user-friendly digital interface.

---

## Features

-  **Leave Application Submission:** Easy-to-use form interface for submitting leave requests.
-  **Fully Responsive Design:** Optimized for desktops, tablets, and mobile devices.
-  **User-Friendly UI:** Intuitive layout built with clean design principles.
-  **Status Tracking UI:** Visually structured layout for reviewing request updates.

---

 Tech Stack

- **HTML5:** Semantic markup for structure.
- **CSS3:** Custom styling and responsive layout rules.
- **JavaScript (ES6+):** Interactive logic and frontend behavior.
